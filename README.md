## What This Repository Includes

- `api_server.py`
  Flask API for dashboard data, health checks, internal reporting, and market intelligence endpoints.

- `bot_set3.py`
  The active `SET3v1` signal logic layer, showing how I turn strategy rules into a working decision engine.

- `recheck.py`
  Follow-up evaluation logic for reviewing outcomes over time, including hit, miss, wait, and TP/SL classification.

- `dashboard.html`
  The private dashboard interface used to inspect totals, history, signal quality, recheck outcomes, and operational health.

- `docker-compose.yml`
  Production orchestration for API, bot worker, nginx, and automation runtime.
